# O. 経路粒度での cos θ

Group A intersection（2,016 遺伝子・16状態 complete case）内で、**30 遺伝子以上**を持つ経路に限定。
基準軸は §2.2 と同じ 猫皮質 CKD3/4。

実行: `python pathway_cos.py` → `python pathway_analysis.py` → `results/pathway/`

**Reactome はローカルの `data/ref` に無いため、GO BP / KEGG / Hallmark の3コレクションで実施しました。**

|---|---|---|
| GO BP | 5,406 | 118 |
| KEGG | 320 | 48 |
| Hallmark | 50 | 27 |
| **合計** | — | **193 経路**（16状態 × 193 = 3,088 セル） |

## 0. 遺伝子数と cos のばらつき（主張の前提となる制約）

同じ大きさのランダム遺伝子集合を 300 回引いたときの cos の広がり:

| 遺伝子数 | IQR | 95% 帯の幅 |
|---|---|---|
| 30 | 0.232 | **0.652** |
| 50 | 0.186 | 0.540 |
| 100 | 0.140 | 0.419 |
| 200 | 0.094 | 0.263 |
| 400 | 0.072 | 0.193 |
| 800 | 0.040 | 0.108 |

**経路の遺伝子数は中央 44、四分位 [34, 61]、最大 131。193 経路のうち 119（62%）が 50 未満です。**
この帯域ではランダムな遺伝子集合でも cos が 0.54–0.65 の幅で振れるため、
**個別経路の cos 値そのものは主張に使えません。**

以下では (a) 分布とパターンのみを述べ、(b) 個別経路に言及する場合は
**n >= 50 かつ cos がランダム集合の 97.5% 点を超えるセルに限り**、記述的な例として扱います。
多重比較のため、個別の経路を「有意」とは呼びません。

## 2. 経路によってモデルの順位は入れ替わる — **はい、大きく**

- **Kendall の W = 0.362**（193 経路 × 12 マウス状態。1 なら全経路で順位が同一）
- 経路ペア間の順位相関: 中央 **+0.315**、5–95% [**−0.374**, +0.846]
- 各経路で cos が最大になった状態は分散する:
  IRI_12mo 25% / IRI_28d 20% / IRI_72h 11% / IRI_48h 9% / IRI_14d 8% / mouse_2W 7% / 他

**単一の「最も良いモデル」は存在しません。**特に IRI_12mo は全体 cos 0.442 と中位ですが、
最も多くの経路（25%）で首位になります。全体 cos の順位は経路レベルの順位を代表しません。

### 3. 集約は分離を壊す — ただし §2.4 と同一設計で計算し直した

**訂正**: 当初は「猫3状態 vs マウス12状態を基準軸への cos θ で分離」する設計で
経路単位 AUC 中央 1.000（89% が >= 0.90）としていた。これは誤りだった。猫3状態は
基準軸とコホート・対照を共有するため §2.4 の共有対照バイアスをそのまま受け、
しかも集約後の 0.541 はペア単位・ペア間 cos θ で単位も量も違っていた。比較になっていない。

`pathway_separation.py` で両者を完全に揃えた。各経路内で**全120ペアの cos θ**（基準軸を
固定しない）を計算し、§2.4 と同じく**対照共有ペアを除外**（87ペア: 種内39 / 種間48）、
種内 vs 種間の AUC を取る。集約側も**同じ87ペア**で計算する。

| 制限 | 全パネル(2,016遺伝子) | 経路単位 中央 [四分位] | 集約 |
|---|---|---|---|
| 制限なし（120ペア） | 0.788 | 0.755 [0.700, 0.817] | 0.541 |
| **対照共有を除外（87ペア）** | **0.813** | **0.788 [0.733, 0.839]** | **0.511** |
| 同一コホートも除外（83ペア） | 0.792 | 0.765 [0.713, 0.821] | 0.481 |

**判定は「中間」ではなく「経路粒度は全パネルの分離をほぼ保ち、集約が壊す」。**
経路単位 0.788 は全パネル 0.813 に近く（33%の経路が全パネル以上）、
集約後の 0.511 は偶然水準。差は +0.277。

ただし経路単位の分離は完全ではない: 四分位 0.733–0.839、AUC >= 0.90 は 13/193、
<= 0.60 は 15/193。**程度の問題として書く。**旧設計の「89% が >= 0.90」は撤回。

サイズ由来の人工物ではない（AUC と遺伝子数の順位相関 +0.035）。
分離が最も弱いのは酸化的リン酸化・ミトコンドリアATP合成・細胞呼吸（0.359–0.372、
0.5 未満＝種間ペアの方が似ている）で、最も強いのは MAPK signaling (0.998)、
autophagy 制御 (0.974)、上皮発生 (0.969)。応答が最も保存されている経路ほど
種を分離しない、という読み方ができる。

## §2 との関係

- §2.3 の cos 0.55 の上限は**全遺伝子平均の性質**であり、経路によっては破れます（§1）。
  本文で「マウスは 0.55 を超えない」と書く際は「全 Group A 遺伝子で見たとき」を明示すべきです。
- §2.2 の「マウス12状態の cos は 0.19–0.55 の狭い帯」も同様に平均の話で、
  経路単位では 0.21–0.96 に広がります。
- 一方で分離そのものは経路レベルでむしろ**強まり**（89% の経路で AUC >= 0.90）、
  §2.3 の結論を弱めるものではありません。弱まるのは「一様な上限」という言い方だけです。
