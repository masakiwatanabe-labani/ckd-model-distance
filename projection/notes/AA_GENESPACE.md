# AA. 遺伝子空間を替えたときの主要結論の再現

## 目的

主解析は Group A intersection（猫皮質・髄質プロテオームとマウスプロテオームの
共通検出遺伝子、complete case 2,016）に限定している。この選択が結論を作って
いないかを、別の 2 空間で同じ 4 量を再計算して確かめる。

## 空間の定義

| 空間 | 定義 | complete case |
|---|---|---|
| Group A intersection | (猫皮質 ∩ 猫髄質) ∩ マウス プロテオーム検出 | 2,016 |
| 全 1:1 orthologue | Ensembl one2one。Group A 制限なし | 7,897 |
| 発現量マッチ Group B | Group B（= 非 Group A）の orthologue から、対照群発現の百分位で Group A に 1:1 マッチ（caliper 0.02、非復元、希少側優先） | 1,618 |

**発現量マッチは完全には達成できない。** Group A は発現上位に偏っており、
90 パーセンタイル超が Group A 554 遺伝子に対し Group B は 156 遺伝子しかない。
2,016 中 1,618（80.3%）しか相手が見つからず、標準化平均差は +0.284 残る
（発現百分位の中央値 Group A 0.812 / マッチ後 Group B 0.758）。
この空間の結果は残差を承知のうえで読む。

実行: `python aa_summary.py`（各空間の実行は `run_aa*.sh`。
環境変数 `XSP_GENES` / `XSP_TAG` で遺伝子空間と出力先を差し替える）。

## 結果

| 量 | Group A（2,016） | 全 orthologue（7,897） | マッチ Group B（1,618） |
|---|---|---|---|
| 猫髄質 CKD1/2 の alpha | **1.020** | 0.796 | 0.930 |
| 同 cos / nrm | 0.790 / 1.291 | 0.730 / 1.091 | 0.707 / 1.315 |
| **alpha > 1.000（基準自身を超える）** | **する** | **しない** | **しない** |
| alpha と cos の順序逆転（髄質 CKD1/2 > 皮質 CKD1/2 in alpha、< in cos） | する | する | する |
| Mantel 経過時間 D_cos | +0.599 (p=0.0040) | +0.637 (p=0.0011) | +0.594 (p=0.0027) |
| **状態ごとの cos x log_time** | **+0.074** [−0.72, +0.72] | **+0.627** [−0.00, +0.96] | **+0.175** [−0.56, +0.79] |
| cat-mouse cos 中央 / 最大 | 0.448 / 0.548 | 0.377 / 0.572 | 0.327 / 0.453 |

## 判定

**3 空間すべてで再現するもの**

1. alpha が方向と振幅を混ぜ、方向で劣る状態を alpha で上位に置くこと
   （猫髄質 CKD1/2 は 3 空間とも皮質 CKD1/2 より alpha が高く cos が低い）。
2. ペア間の Mantel が経過時間と方向で結びつくこと（+0.594〜+0.637、p < 0.01）。
3. 異種ペアの観測 cos が天井に届かないこと（最大 < 最小天井、天井超え 0/48）。
4. 全パネルの cat-mouse 分離（AUC 0.743〜0.791、いずれも p < 0.01）。
5. 経路単位の分離が集約後より高いこと（0.788 > 0.511 / 0.788 > 0.633 / 0.754 > 0.608）。

**再現しないもの（本文で Group A 空間に限定する）**

1. **alpha が基準自身の 1.000 を超えること。** 他の 2 空間では 0.796 / 0.930。
   反例としての「超える」事象は Group A 空間に固有。順序逆転そのものは残る。
2. **経過時間と基準軸への alignment が無関連であること。** 全 orthologue 空間では
   +0.627（並べ替え p = 0.031）で、正の関連が検出される。IRI 12 か月の cos が
   0.442 → 0.529、28 日が 0.484 → 0.501 と上がることによる。マッチ Group B では
   +0.175。3 空間の CI は大きく重なるので「空間によって違う」とも
   「同じ」とも結論できない。点推定の幅をそのまま示す。
3. **集約後に偶然水準へ落ちること。** 0.511 は Group A 空間のみ。他の 2 空間では
   0.633 / 0.608 で、分離は落ちるが偶然水準ではない。落ちる向きは 3 空間で共通。

# 付記: 査読対応で判明した誤り（2026-09-15）

1. **特許は基準超えを想定済み**。US 7,519,519 B1 の利点一覧に
   "Hypermatches as well as anti-matches to the signature property can be evaluated"。
   「基準超えは検討されていない」という記述は撤回した。
2. **§2.5 の 0.9 以上のセル数**。条件なしでは 34 セル、n>=50 かつ乱択 97.5% 超では
   **3 セル**（focal adhesion の IRI 7d / 72h / 28d）。従来「2セル」としていたのは
   IRI 28d の脱落。分母も 2,316 ではなく条件を満たす 888 セル。
3. **Fig 6A の保存性解釈**。最高同一性四分位は種間 cos が最低（0.327）だが同種は
   ほぼ横ばい（0.685）で、**中央値差はこの四分位が最大（0.358、他は 0.203–0.264）**。
   「保存性が高い側ほど種を区別しない」は逆であり、当該段落は撤回した。
4. **Bishop らの手法**。本文（PMC9536645）を取得して確認したところ GSEA と
   Ingenuity Pathway Analysis を使用。本稿の「標準化 Δ の平均」とは別手法なので、
   経路解析一般への一般化は撤回した。
5. **集約の向き**。AUC 0.511 だけでは両群が似たのか離れたのか決まらない。分布を見ると
   **両群とも上がり**（種内 0.724→0.869、種間 0.447→0.882）、種間が約2倍上がって
   順序が消える。「情報が薄まった」ではなく「集約が種間を一致の側へ動かす」。
6. **cat_CKD12 の alpha**。NUMBERS.md に 0.545 とあったが実測 0.544488（3桁で 0.544）。

# 付記2: 個体ブートストラップの実装バグと撤回（2026-09-15、査読2回目）

`pair_uncertainty.py` の初版に 3 つの誤りがあり、「異種 48/48 ペアで天井との差の
区間が 0 を除外」という値を出していた。**撤回**。

1. 「異なる個体が2頭未満」の判定を `np.unique(case)` で行っていたが、`case` は
   遺伝子 × 標本の float 行列なので、返るのは数千個の発現値。条件は一度も成立せず、
   未定義反復が常に 0 件になっていた。n=3 の復元抽出で全部同一になる確率は
   3(1/3)^3 = 1/9 なので、本来は 1 群あたり約 11% 出る。
2. 分割半を復元抽出後の**多重集合**に対して行っていたため、同じ個体が両半分に
   入りえた。これは r_half を上振れさせ、天井を押し上げ、gap を押し上げる。
   **主張に有利な方向のバイアス**。
3. ネコの皮質と髄質は同一個体（対照6頭は完全共通、CKD1/2 は 8/7 頭中 6 頭、
   CKD3/4 は 7/5 頭中 5 頭が共通）だが、独立に再抽出していた。

修正後（個体 ID で判定、分割半は異なる個体のみ、ID 集合が交わる群はプールで同時抽出、
未定義反復は再抽出せず割合を報告）の結果:

| 量 | 修正前（誤り） | 修正後 |
|---|---|---|
| 未定義反復の割合 | 0.000 | 中央 0.118 [0.098, 0.235] |
| 区間が 0 を除外する異種ペア | 48 / 48 | **26 / 48** |
| うち猫側が高信頼（r_half 0.841 / 0.851） | — | **24 / 24** |
| うち猫側が低信頼（0.568 / 0.616） | — | **2 / 24** |
| ジャックナイフで gap <= 0 | 1 / 48 | 1 / 48 |

主張は条件つきになった。猫側が信頼できる 2 状態では差が残るが、残り 2 状態では
分離できない。本文・図・NUMBERS・verify_numbers をこの値に差し替えた。

# 付記3: 集約の効果は中心化が決めている（2026-09-15、査読3回目）

状態ごとに遺伝子方向へ z 標準化するとき、**標準偏差による除算は cos θ で相殺される**
（経路平均の前後いずれでも、状態ごとの定数倍だから）。したがって cos を変えているのは
中心化だけであり、

    cos(z_i, z_j) = Pearson(Δ_i, Δ_j)

が成り立つ。機械精度で確認した（最大差 2.8e-15 / 3.3e-16 / 1.1e-15）。

この整理により、条件を「中心化の有無」で並べ替えると結果が明快になる。

| 条件 | 種内 | 種間 | AUC |
|---|---|---|---|
| 1. Δ そのままの cos θ | 0.724 | 0.447 | 0.813 |
| 2. 状態ごとに中心化（= Δ の Pearson 相関） | 0.709 | 0.551 | 0.759 |
| 3. 中心化した Δ の経路平均（本稿の集約） | 0.869 | 0.882 | **0.511** |
| 4. 中心化しない Δ の経路平均 | 0.896 | 0.489 | **0.899** |

**同じ経路平均が、各状態の全遺伝子平均を先に引くかどうかで逆方向になる。**
引けば偶然水準、引かなければ遺伝子単位（0.813）より良い分離。動くのは種間ペア
（0.447 → 中心化ありで 0.882、なしで 0.489）。
「二段構成のスコア固有」という以前の表現より、何が判断を変えたのかが明確になる。
