# Obtaining the data

None of the primary data are redistributed with this repository. Some of it is
under third-party copyright, and some is deposited elsewhere and should be cited
at source. This file lists every input the analysis needs, where to get it, what
to call it, and its MD5 checksum so you can confirm you have the same bytes we did.

Two of the four sources download automatically; two need a browser.

```
data/
  raw/        # not redistributable - obtain manually (steps 1 and 2 below)
  external/   # public repositories - mostly automatic (steps 3 to 6)
  ref/        # generated by src/00_fetch_refs.py, not stored here
  interim/    # generated by src/01_load.py, not stored here
```

Checksums are MD5. On macOS use `md5 <file>`; on Linux `md5sum <file>`.
A mismatch usually means the provider has revised the file; the analysis may
still run, but the numbers in the paper were produced with the versions below.

---

## 1. Feline spontaneous CKD (manual)

Supplementary Data 3 of:

> Li Q, Cominetti O, Holzwarth JA, Summers S, Wang X, Dayon L.
> Integrated multi-omics analysis of renal metabolism in domestic cats with
> spontaneous chronic kidney disease. *Commun Biol* 2025.
> doi:10.1038/s42003-025-09164-8

Download the supplementary file from the article page and place it at:

```
data/raw/42003_2025_9164_MOESM3_ESM.xlsx
```

| File | MD5 | SHA-256 |
|---|---|---|
| `42003_2025_9164_MOESM3_ESM.xlsx` | `300b8dab4290dc034f84d7caeba4709d` | `0037263600ec06f688a453ddbc2732e754c9034df7b4486713bfc76663ebf136` |

The file is the publisher's supplementary file and is not redistributed here; download it from the article page and check it against both digests. Downloaded 2026-08-26 for the analysis reported in the revision.

The workbook supplies four sheets used here: `S3 RNA cortex`, `S4 RNA medulla`,
`S5 Protein cortex`, `S6 Protein medulla`. Sheet names are configurable in
`config/config.yaml` under `cat_sheets`.

Note that the protein sheets are centred per protein (row mean is approximately
zero). The pipeline detects this and restricts that layer to rank-based
statistics; see the Methods of the paper.

## 2. Pod-TRECK mouse (manual, on request)

The Pod-TRECK transcriptome (GSE299326) and the matching in-house proteome are
not redistributed here. The transcriptome is available from GEO.

The quantification table the pipeline reads is published with the article as
**Supplementary Data S1**, `Supplementary_Data_S1_PodTRECK_proteome.xlsx`
(1,683,246 bytes, SHA-256
`6194c68111856b1e4e01cb94084b2eeb0f1e6b12fb1682fd8f1faace4a6a49bc`). It carries the
same values as the source table, with the document properties cleared, and the
analysis can be reproduced from it: `af7_attach_source_table.py` recomputes the
Group A selection from that file and obtains 2,240 genes and 2,016 complete cases.

```
data/raw/all_fpkm_TRECK.xlsx
data/raw/<the proteome quantification table>     # = Supplementary Data S1
data/raw/<three pairwise-comparison workbooks>   # provenance only, not read
```

| File | MD5 |
|---|---|
| `all_fpkm_TRECK.xlsx` | `dd41c4d866cab8bd48e8254b01dc8ac6` |

The source table is a contract analysis whose file name carries the provider's job
number, so the name is not given here; `projection/code/revision1/local_source.py`
reads it from a local file or from `CKD_PODTRECK_SOURCE`. Working from
Supplementary Data S1 instead needs neither.

## 6. KPMP regional proteomics (manual)

The KPMP Atlas requires a click-through agreement, so this one cannot be
scripted. Go to the KPMP Atlas Explorer repository, find the regional
proteomics aggregated data (doi:10.48698/mg7h-bc51), accept the terms, download
`DataLake_DEPs.txt`, and place it at:

```
data/external/KPMP/DataLake_DEPs.txt
```

| File | MD5 |
|---|---|
| `DataLake_DEPs.txt` | `98ec4e2426df132b03c2fa0f88c3bcee` |

This is a long-format table; the pipeline selects the pre-computed
`CKD.vs.HRT.in.TI` and `CKD.vs.HRT.in.G` contrasts.

## Reference tables (automatic, not stored here)

```bash
python src/00_fetch_refs.py
```

populates `data/ref/` on first run (a few minutes) with orthologue tables and
gene synonyms from Ensembl BioMart, secretome annotation from UniProt, and gene
set collections from MSigDB via GSEApy.

These are not committed to the repository. The MSigDB KEGG collection carries
redistribution conditions that the other collections do not, so we let each user
retrieve it under the MSigDB terms of use rather than shipping a copy. By
running this script you are retrieving those gene sets under MSigDB's licence.

If you have no network access, populate `data/ref/` by hand with the files the
script would otherwise write; every later step reads from disk.

## Checking what you have

```bash
# macOS
find data/raw data/external -type f ! -name '.gitkeep' -exec md5 {} \;
# Linux
find data/raw data/external -type f ! -name '.gitkeep' -exec md5sum {} \;
```
